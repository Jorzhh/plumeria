Preguntas de Reflexion

¿Que funcion cumple la escena en Three.js? Es el contenedor 3D donde se posicionan todos los objetos, luces y camaras

¿Para que sirve la camara? Define el punto de vista, angulo de vision y la perspectiva desde donde el usuario observa el entorno

¿Que hace el renderer? Transforma la escena 3D y la camara en una imagen 2D que se dibuja en el navegador en cada fotograma

¿Que permite hacer OrbitControls? Otorga control interactivo para orbitar, rotar, desplazar y hacer zoom alrededor de un punto de interes

¿Que es el raycasting y para que lo usaste? Es una tecnica que dispara un rayo desde la pantalla hacia la escena 3D para detectar intersecciones con objetos y permitir la seleccion con el mouse

¿Que dificultades tuviste al cargar modelos .glb o .gltf? ajuste de escalas gigantes o diminutas y el manejo de objetos anidados dentro de las mallas

¿Como podrias usar este visor 3D en un proyecto real? En simulacion para gemelos digitales, videojuegos web en navegador, bioinformatica para manipular moleculas o en e-commerce para configuradores de productos 3D
