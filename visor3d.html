Cuestionario Teórico del Proyecto

1. ¿Qué función cumple la escena en Three.js?

Es el contenedor principal o el "escenario" virtual donde se colocan todos los elementos 3D (geometrías, luces, cámaras y modelos) para que puedan ser renderizados en pantalla.

2. ¿Para qué sirve la cámara?

Define el punto de vista del usuario. Simula el ojo humano o una lente cinematográfica, determinando qué parte del mundo 3D es visible y cómo se proyecta en la pantalla 2D.

3. ¿Qué hace el renderer?

Toma la escena y la cámara como entradas y calcula los gráficos matemáticos fotograma a fotograma para dibujarlos dentro del elemento HTML Canvas usando WebGL.

4. ¿Qué permite hacer OrbitControls?

Permite al usuario interactuar libremente con el entorno mediante el mouse o la pantalla táctil para rotar alrededor de un objetivo, hacer zoom y desplazar la vista (pan).

5. ¿Qué es el raycasting y para qué lo usaste?

Es una técnica para calcular intersecciones entre un rayo lanzado desde la posición del mouse en la pantalla y los objetos tridimensionales de la escena. Lo usé para detectar qué objeto clics el usuario y cambiar su color o mostrar su información.

6. ¿Qué dificultades tuviste al cargar modelos .glb o .gltf?

Principalmente problemas con las rutas relativas de los archivos o texturas externas asociadas al modelo, así como asegurar que el cargador asíncrono (`GLTFLoader`) maneje correctamente la escala y posición inicial.

7. ¿Cómo podrías usar este visor 3D en un proyecto de simulación, videojuegos, bioinformática o modelado 3D?

Permitiría visualizar estructuras moleculares en bioinformática, renderizar componentes interactivos en simulaciones industriales, o armar prototipos visuales rápidos para videojuegos web sin instalar plugins pesados.
