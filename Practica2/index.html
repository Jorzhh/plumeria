Respuestas de la Práctica

¿Qué tema representa tu visor 3D?

Representa un "Mini museo 3D" o visor de figuras de colección interactivo, combinando geometría básica con modelos complejos.

¿Qué objetos agregaste a la escena?

Agregué cinco figuras primitivas (un cubo, una esfera, un cilindro, un toroide y un cono) y un modelo externo complejo.

¿Qué información aparece cuando seleccionas un objeto?

Aparece un panel interactivo mostrando el Nombre del objeto, el Tipo (si es geometría primitiva o modelo externo), una Descripción y un Dato extra (como su función, categoría o colección).

¿Cómo implementaste el raycasting?

Instanciando THREE.Raycaster() y capturando el evento click del mouse. Las coordenadas 2D de la pantalla se normalizan y el raycaster proyecta un vector desde la cámara hacia la escena 3D, detectando intersecciones con un arreglo llamado interactableObjects.

¿Qué controles agregaste para modificar la escena?

Agregué seis controles: Pausar/Reanudar animación, Cambiar color aleatorio, Ocultar/Mostrar el modelo externo, Enfocar el siguiente objeto (movimiento de cámara), Reiniciar la posición de la cámara y un Slider para modificar la intensidad de la luz direccional.

¿Qué modelo .glb o .gltf utilizaste?

Utilicé un modelo .glb de un Lego Batman.

¿Qué parte del proyecto fue la más difícil?

Ajustar la escala del modelo externo (Lego Batman) ya que al importarlo era gigante, y lograr que los botones de la interfaz HTML no interfirieran con el raycaster de la escena 3D.

¿Cómo podrías mejorar este visor si lo conectaras después con PHP, FlightPHP y SQLite?

Podría crear una base de datos en SQLite con la información de cada figura. Usando FlightPHP crearía una API REST. Así, en lugar de tener la información "quemada" (hardcodeada) en JavaScript, haría una petición fetch() al servidor PHP para obtener y mostrar datos dinámicos, permitiendo actualizar el museo sin modificar el código fuente 3D.
